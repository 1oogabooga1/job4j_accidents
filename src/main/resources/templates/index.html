About the Project

A web application for reporting and managing traffic violations, built with Java, Spring MVC, Hibernate, Thymeleaf, and PostgreSQL.

Users can submit violation reports with an address, car number, description, and photo, while traffic inspectors can review reports and update their status.

The project demonstrates a classic server-side MVC architecture with controller → service → repository → database, role-based interaction, status management, image upload, and searchable violation records.
