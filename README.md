# job4j_accidents

## About the Project

**job4j_accidents** is a training Spring project for managing traffic violation reports.

The system allows regular users to create accident/violation reports, while traffic inspectors can review these reports and update their status.

The project is currently at an early stage of development.

---

## Main Features

The system has two roles:

- **User**
- **Traffic Inspector**

A user can create a traffic violation report and provide:

- violation address;
- vehicle plate number;
- violation description;
- violation photo.

Each report has a status:

- **Accepted**
- **Rejected**
- **Completed**

---

## Main Page

The main page of the system includes:

- report search;
- table with traffic violation reports.
